# CI/CD and supply chain

Read workflows, reusable workflows, actions, dependency manifests and lockfiles.
Trace untrusted PR data into shell commands, expressions, artifacts and privileged jobs.
Check pull_request_target usage, checkout of untrusted refs, token permission scope,
secret exposure, cache/artifact poisoning, release signing and environment protection.
Inspect AI-agent workflow inputs for prompt injection and secret-bearing tool access.
Check action pinning, install scripts, package sources, lockfile integrity and trust.
Vulnerability results require exact resolved versions, advisory date and reachability.
Record license/ecosystem gaps; unsupported dependency formats need separate review.
Do not equate a clean dependency scan with uncompromised supply chains.
