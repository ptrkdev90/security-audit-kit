# JavaScript, TypeScript and Python

Inspect lockfiles, runtime/framework versions and lifecycle hooks before installation.
JavaScript: unsafe DOM sinks, eval/Function, command construction, prototype pollution,
path traversal, server-only secrets bundled into clients, auth middleware, SSRF,
object merging, upload handlers and dangerous development endpoints.
Python: pickle/unsafe YAML, eval/exec, subprocess shell use, dynamic imports, template
escaping, path joins, SQL construction, authentication decorators and async job scope.
Check session/CSRF defaults and framework-specific defenses in their actual context.
Do not import target modules for static discovery. Treat tests and package installation
as target execution. Pin the dependency snapshot and record scanner ecosystem support.
